# DevOps Food Donation Application

A full-stack web app built with Django for efficient food donation management.
The app enables organizations and volunteers to manage, monitor, and track food donations so that surplus food can reach deserving individuals. The project having been built with DevOps principles in mind is CI/CD deployable and can be scaled with AWS Elastic Beanstalk.

##  Features

- Households registration and management
- NGOs registration and management
- Track donations of spare food
- Donate to NGO's
- Donation status notification
- Integration with MySQL database
- Deployment in AWS Elastic Beanstalk
- Integration with CI/CD using AWS CodePipeline (buildspec.yml)

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Database:** MySQL instance hosted in AWS RDS
- **CI/CD:** AWS CodePipeline, AWS CodeBuild
- **Deployment:** AWS Elastic Beanstalk
- **Other:** `.ebextensions` for Elastic Beanstalk environment configuration.
